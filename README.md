# SQL Practice and Quantitative Data Analysis

A structured repository containing solved SQL exercises, challenge sets, and data analysis queries focused on database management, aggregation, and complex query optimization.

## 📌 Repository Structure

* **`01_sqlbolt_exercises.sql`**: Comprehensive query solutions covering relational algebra, joins, aggregate functions, and table constraints from SQLBolt.
* **`02_hackerrank/`**: Solutions to intermediate and advanced database challenges on HackerRank, featuring window functions, subqueries, and grouping sets.

## 🛠️ Key SQL Skills Demonstrated

* **Data Filtering & Aggregation:** `GROUP BY`, `HAVING`, conditional expressions (`CASE WHEN`).
* **Complex Joins & Subqueries:** Inner/Outer joins, self-joins, nested queries, and CTEs (Common Table Expressions).
* **Data Manipulation & Schema Management:** DDL/DML execution and query performance optimization.
